# Dataset

This project uses the **Level 3 Electric Vehicle Charging Dataset** published by DESL-EPFL.

Source:
https://github.com/DESL-EPFL/Level-3-EV-charging-dataset

The dataset contains EV charging session data collected from a Level 3 charging station in southwestern Switzerland between April 12, 2022 and July 4, 2023.

The original dataset is provided under the MIT License.
